# 模型执行权限

本模块是 AgentRepo 的独立权限域，使用 `.runtime/authorization.sqlite`，只读引用实体图。不向实体节点添加角色、权限或权限组字段。

## 固定语义

基础动作：`discover/read/create/update/delete/execute/transfer/delegate/grant`。多项要求必须全部允许；明确禁止优先，无允许依据则拒绝。权限组之间允许补充，但每条规则的条件整体满足，不拼接条件。原子性、可恢复性、幂等性、外部影响和敏感度属于行为属性。

预置组：管理员组 `administrator`、内部组 `internal`、外部组 `external`。不会自动绑定任何人。管理员默认策略接纳已核验、具有执行拦截的能力；内部默认策略仅接纳普通、无外部影响、已核验的读取能力；外部组默认无授权。管理员也不绕过明确禁止或执行边界。

组织、部门、个人通过 `auth_bindings` 绑定权限组。部门直属成员与包含下级部门分别配置。身份必须使用可信账号、来源和稳定实体标识；不按姓名合并。归属缺失、过期、截断或来源冲突拒绝授权。

## 资源与默认授权

公开工具目录和 Agent 技能索引提供扫描输入。描述、名称及工具声明不作为安全证明。新增资源为待核验；定义变化产生新版本并撤销旧核验状态。分类接口只修改标签、行为属性，不能制造执行适配器或改变能力动作。

默认策略产生带策略版本和资源版本的授权记录。资源版本变化后旧自动授权不再有效。修改默认策略不会追溯改变既有记录；立即封禁使用明确禁止规则。

## 执行入口

插件清单声明 `contracts.trustedToolPolicies`，运行时注册 `agent-repo-authorization`。需要宿主支持公开 `registerTrustedToolPolicy` 并显式启用插件。不能以仅存在函数就推断生产注册成功。

当前可信适配器解析操作要求，再由统一服务检查资源、实体归属、权限组和条件。未知或歧义适配器拒绝。第三方适配器通过 `@openclaw-plugins/agent-repo-api/authorization` 同进程注册，模型参数不能注册适配器。

审计模式只记录，不提供强制保护。强制模式拒绝未知身份、未知资源、未适配操作和服务异常。运行权限快照保存原资源版本及授权条件，新增权限不扩大已有快照，当前撤权仍生效。Worker 插件调用使用宿主签发的 job 级调用范围，恢复执行保留 job 范围。

## 管理

AgentRepo → 权限中心展示资源、组、绑定、规则、模拟及审计。管理写入使用宿主 `operator.admin`，不暴露为模型工具。实体绑定写入前检查实体存在及类型。版本冲突必须刷新，禁止覆盖。权限模拟不调用业务能力。

## Worker 调用边界

Worker 现有 11 个工具动作已按实际行为登记：queues/projects/list/status/wait 需要执行与读取权限，tag/cancel 需要执行与修改权限，await_user 额外需要传出权限。run/reply/steer 可能启动或影响外部执行器，属于仅显式授权的宽泛执行资源，要求全部基础动作；三个默认组都不会自动获得这类资源的授权。这不是 Worker 沙箱，也不代表原生文件、网络和任务全生命周期已完成权限收敛。

## 已核实的宿主接口缺口

当前依赖的公开 SDK 中，`PluginHookBeforePromptBuildResult.toolsAllow` 只收窄可选工具，不提供技能过滤字段，不能作为技能正文加载权限的证明。AgentRepo 自己附加的技能目录和宿主原生技能加载都仍需明确的受控入口。

`PluginHookMessageContext` 的公开合同明确说明：发送路径尚未携带用于关联原执行轮次的 `runId`；`sessionKey` 无法区分同一会话中的并发执行。不能用“此会话最近一次请求人”代替结果所属任务的授权主体。完整结果交付拦截需要发送路径传递可信任务/轮次标识，并在每次真实发送前复核其权限。

这些缺口不影响已覆盖工具入口的独立鉴权，但阻止将当前强制模式宣称为“大模型所有能力均已受控”。部署前仍须完成上述路径；不能通过删除验收项、借用其他会话身份或把所有输出一律丢弃来代替实现。
