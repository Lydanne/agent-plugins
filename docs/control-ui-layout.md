# Control UI 布局与弹层约定

沿用宿主背景、文字与现有绿色/蓝灰强调色。页面优先展示当前对象和结果，统一标题、工具栏、内容区、分页的间距与对齐。

## 操作分层

- 搜索、常用范围、状态和刷新保留在列表附近；危险操作不作为主按钮。
- 审计的身份、对象、操作类型及时间范围放入高级筛选；人员账号关联与完整度也在筛选弹层中配置。
- 高级筛选独立维护草稿。取消不影响已应用条件；重置清空草稿，点击应用才重新查询。显示已应用条件数量。
- 简短解释使用 HelpTip / Popover，异常、部分失败和权限错误仍在相关操作附近展示。
- 编辑人员、组织同步管理、回收站保留设置、日志清理确认使用 Dialog。表单错误留在弹窗内，保存失败保留草稿；不得因布局调整重放未知结果。
- Worker 侧栏保留搜索与项目范围，排序进入会话筛选，热度解释按需打开；四类详情入口保持不变。

## 组件与生命周期

使用共享包中的 Reka/shadcn-vue Dialog、Popover、Input、NativeSelect 和 Button，弹层挂到每个实例独立的 Portal 根。

Dialog 默认跟随 Agent 和会话目标关闭。跨会话管理表单显式使用 `sessionScoped=false`，避免切换无关会话时丢失编辑；切换 Agent、隐藏、权限变化和卸载仍关闭弹层并废弃旧响应。键盘 Escape、焦点返回、嵌套弹窗和主题跟随须通过浏览器回归。

窄容器下工具栏换行、表单改单列，长 ID 与路径允许换行；保留日志虚拟滚动与原始记录惰性渲染。
